Importer des articles

Une page de catégorie contient en général une vingtaine d'articles. Les photos, titres et prix en euros sont récupérés automatiquement.

Pour les sites qui bloquent la lecture automatique (comme Action). Le favori lit la page dans ton navigateur, puis envoie les articles ici.

  1. Glisse ce bouton dans ta barre de favoris (Chrome : Cmd/Ctrl + Maj + B pour l'afficher) : ⚡ Importer vers Action bla ghla
  2. Ouvre une page de catégorie sur le site (ex. Action → Cuisine).
  3. Clique sur le favori, choisis le nombre de pages : cette fenêtre se rouvre avec les articles.

Ordinateur uniquement. Sur téléphone, utilise le PDF ou « Code ».

  1. Ordinateur : ouvre la page du site, puis Cmd+Option+U (Windows : Ctrl+U) pour voir son code.
  2. Android (Chrome) : écris view-source: juste avant l'adresse de la page, puis valide.
  3. Sélectionne tout, copie, et colle ci-dessous. Pour plusieurs pages, colle-les à la suite, l'une après l'autre.

iPhone : Safari ne montre pas le code des pages, utilise plutôt le PDF ou l'ordinateur.
